# Competitor analysis (2026-11)

Based on the publicly known feature sets of widely used personal-finance apps. Prices/features change; treat as a snapshot.

| App | Known for | Weak spots |
|---|---|---|
| **Monefy** | Fastest entry: tap a category, type amount, done (~3 taps). Simple pie-chart home | Shallow reports; sync via Dropbox/Google Drive only |
| **Money Manager (Realbyte)** | Very popular on Android; calculator keypad, calendar view, accounts, budgets | Dated UI; desktop is a separate paid flow |
| **Money Lover** | Wallets, budgets, events, recurring, bill reminders, multi-language | Many features behind subscription; ads |
| **Wallet (BudgetBakers)** | Bank sync, rich reports, templates, shared accounts | Heavy UI; best features paid; bank sync not available locally |
| **Spendee** | Beautiful UI, shared wallets, budgets | Premium needed for multiple wallets/sync |
| **YNAB** | Zero-based budgeting method ("give every shekel a job") | Paid only, steep learning curve, no Arabic |

## What users expect (common to the leaders)

1. **Record a transaction in seconds** — one obvious "+" button, amount first, category as an icon grid, today's date preselected.
2. **Home shows this month**: income, expenses, net, and recent transactions.
3. Transactions list with search and day grouping.
4. Budgets per category with progress bars and warnings.
5. Reports: category pie/donut, month-over-month.
6. Recurring transactions and reminders.
7. Multiple accounts/currencies, transfers that don't count as spending.

## Where Personal Wallet can win

- **Arabic-first with real RTL**, ILS/USD/JOD with exact 3-decimal JOD — most competitors treat Arabic as a translation and ILS/JOD poorly.
- **Free multi-device sync with offline-first** (Monefy/Spendee charge or rely on file sync).
- **Exact money** (integer minor units, ledger balances) and privacy (no ads, RLS-isolated data).
